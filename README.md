# Inkwell — React + TypeScript + Tailwind blog

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # type-check + production build

Stack: Vite, React 18, TypeScript, Tailwind CSS 3, Zustand, lucide-react.
Routes use the URL hash (`#/post/3`), so no router dependency or server config is needed.
